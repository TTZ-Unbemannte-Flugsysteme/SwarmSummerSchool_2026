# Bill of Materials (BOM)

This section lists all the necessary hardware components for the drone build.

## Essential Components

| Item | Description | Quantity | Link / Reference |
| :--- | :--- | :--- | :--- |
| **Frame** | E.g., F450 or F330 quadcopter frame | 1 | |
| **Motors** | Brushless motors (e.g., 2212 920KV) | 4 | |
| **ESCs** | Electronic Speed Controllers (e.g., 30A) | 4 | |
| **Propellers** | Matched to motors (e.g., 9450 or 1045) | 4 | |
| **Flight Controller** | E.g., Pixhawk 4 or Pixhawk 6C | 1 | |
| **GPS Module** | M8N or similar GPS with Compass | 1 | |
| **Battery** | LiPo Battery (e.g., 3S or 4S, 5000mAh) | 1 | |
| **PDB / PMU** | Power Distribution Board / Power Module | 1 | |
| **Radio Receiver** | Compatible with your RC Transmitter | 1 | |

## Tools Required

- Soldering iron and solder (See [Welding Guide](assembly/welding.md))
- Nippers and wire strippers (See [Nipping Guide](assembly/nipping.md))
- Hex keys and screwdrivers
- Multimeter (for testing connections)
- Heat shrink tubing and zip ties
