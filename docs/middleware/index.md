# Advanced Middleware

For advanced swarm control and algorithmic deployments, we utilize the **DroneManager** middleware developed by AImotion Bavaria. 

DroneManager provides a robust, high-level interface for managing multiple drones, orchestrating complex swarm behaviors, and bridging the gap between algorithmic simulation and real-world hardware deployment.

## Repository

You can find the complete source code, documentation, and installation instructions for DroneManager in the official repository:

!!! tip
    **[AImotion-Bavaria / DroneManager](https://github.com/AImotion-Bavaria/DroneManager)**

## Integration

When you are ready to move beyond the basic RC flight and into advanced autonomous control:
1. Ensure your companion computer (Raspberry Pi) is correctly wired to the flight controller's telemetry port.
2. Clone the DroneManager repository onto your companion computer.
3. Follow the setup instructions in the repository's README to establish the MAVLink bridge.
